INTRODUCTION                                                       *obs-intro*

obs.nvim manages a local Markdown vault from Neovim. It provides wiki-link,
journal, template, tag, backlink, rename, move, and link-copy workflows.
Neovim 0.11 or newer is required. Wiki-link completion requires Neovim 0.12.

===============================================================================
SETUP                                                               *obs-setup*

>lua
    require("obs").setup {
        vault_home = "~/Notes",
        vault_name = "Notes",
        templater = {
            home = "~/Notes/meta/templates",
            note_template_name = "note",
        },
        journal = {
            daily_template_name = "daily",
            weekly_template_name = "weekly",
        },
    }
<

The complete option types are documented in lua/obs/vault.lua. Templates use
Markdown files and support {{date}}, {{title}}, and configured extra providers.

COMMANDS                                                         *obs-commands*

                                                *:ObsNvimTemplate*
:ObsNvimTemplate        Select and insert a template.
                                                *:ObsNvimFollowLink*
:ObsNvimFollowLink      Follow the wiki link under the cursor.
                                                *:ObsNvimNextLink*
:[count]ObsNvimNextLink[!]  Move forward through links; ! includes web and
                            Markdown links.
                                                *:ObsNvimPrevLink*
:[count]ObsNvimPrevLink[!]  Move backward through links.
                                                *:ObsNvimRandomNote*
:ObsNvimRandomNote      Open a random vault note.
                                                *:ObsNvimNewNote*
:ObsNvimNewNote         Create a dated note.
                                                *:ObsNvimDailyNote*
:[count]ObsNvimDailyNote[!] [date]
                            Open or create a daily note; ! opens the calendar.
                                                *:ObsNvimWeeklyNote*
:ObsNvimWeeklyNote      Open or create this week's note.
                                                *:ObsNvimBacklinks*
:ObsNvimBacklinks       Select a backlink to the current note.
                                                *:ObsNvimTags*
:ObsNvimTags            Select a vault tag and note.
                                                *:ObsNvimTag*
:ObsNvimTag [tag]       Open a note for a tag or the tag under the cursor.
                                                *:ObsNvimRename*
:ObsNvimRename          Rename the current note and update matching wiki links
                        on disk and in loaded buffers. The current buffer
                        stays open with unsaved edits and is associated with
                        the new path; write it explicitly to save. Unsaved
                        edits in other affected buffers remain unsaved, while
                        clean buffers stay clean. If an affected buffer is
                        nonmodifiable, or the destination is already open in
                        another buffer, the rename is rejected before files
                        or links are changed.
                                                *:ObsNvimMove*
:ObsNvimMove            Move the current note inside the vault. If a note with
                        the same name already exists in the destination, the
                        move is rejected with a notification and the source
                        is preserved.
                                                *:ObsNvimCopyObsidianLinkToNote*
:ObsNvimCopyObsidianLinkToNote  Copy an Obsidian URL.
                                                *:ObsNvimCopyWikiLinkToNote*
:ObsNvimCopyWikiLinkToNote      Copy a wiki link.
                                                *:ObsNvimOpenInObsidian*
:ObsNvimOpenInObsidian  Open the current note in Obsidian.

COMPLETION                                                     *obs-completion*

On Neovim 0.12+, built-in completion is enabled for Markdown buffers in the
vault. Use CTRL-X CTRL-U inside [[...]], or configure
completion = { enabled = false } to opt out. obs.nvim does not replace
'omnifunc' or enable 'autocomplete'. Inside an existing link, candidates are
bare note names. Completing one replaces the entire note name, including text
to the right of the cursor, while preserving the closing ]] and any |alias or
#heading. For an incomplete link without that boundary, the closing ]] is
added as before.
